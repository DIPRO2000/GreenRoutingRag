# Credits and Starting Point

This project is being developed by our team as **GreenRouting RAG**.

The initial implementation base was provided as the local **EcoWeave** project by a team member. We are extending and evaluating that base for our own project, including the routing policy, cache validation, energy/carbon reporting, benchmarking, tests, and documentation.

Before publishing the repository publicly, confirm the original author's permission and add the original repository URL here if one is available. The inherited EcoWeave folder did not contain a `LICENSE` file, so this project must not describe the inherited code as open source without written permission or an explicit licence.

The original base README is preserved at `docs/base-reference.md` for reference. Generated environments, caches, databases, vector indexes, and private uploaded documents are intentionally excluded from this clean copy.
