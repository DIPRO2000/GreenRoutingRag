I recommend:

1. Document deletion and index rebuilding  
2. Energy-aware retrieval using adaptive `top_k`  
3. Explainable routing/cache messages  
4. Quality–carbon benchmark chart  

These can make the demo noticeably stronger without depending completely on Workstreams 2 and 3.

### Good later-semester additions

- Carbon budget enforcement
- Live electricity-grid carbon intensity
- Learned routing using machine learning
- OCR for scanned PDFs
- DOCX and spreadsheet support
- Privacy/PII detection
- Multi-user access control

The honest innovation claim should be:

> The individual techniques already exist, but GreenRouting combines document-grounded retrieval, semantic caching, adaptive model selection, quality safeguards, and carbon measurement into one locally measurable system.

That combined quality-versus-energy evaluation is what gives the project value.
